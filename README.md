# Student Habits vs Academic Performance - IDS1 Mini Project

## Setup (Windows)
1. Download the dataset from Kaggle (jayaantanaath/student-habits-vs-academic-performance).
2. Save the CSV as `data/student_habits_performance.csv` (or upload it from the app sidebar).
3. In a terminal inside this folder:
   pip install -r requirements.txt
   streamlit run app.py

## Files
- ids_core.py : cleaning, models (Linear Regression, Random Forest), K-Means, prediction
- app.py      : Streamlit front end (6 pages)
